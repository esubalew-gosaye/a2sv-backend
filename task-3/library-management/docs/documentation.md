# Console-Based Library Management System

## Overview
This is a console-based system to manage books and members using Go, demonstrating the use of:
- Structs
- Interfaces
- Maps and Slices
- Console Input/Output

## Features
- Add, Remove, Borrow, Return Books
- List Available Books
- List Borrowed Books by a Member

## Folder Structure
- `models/`: Contains Book and Member struct definitions.
- `services/`: Business logic for managing books and members.
- `controllers/`: Handles console interactions.
- `main.go`: Application entry point.

## Getting Started
```bash
go run main.go
